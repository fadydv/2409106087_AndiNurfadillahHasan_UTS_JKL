# UTS Jaringan Komputer Lanjut

## Struktur Project
- `identitas.py`: Modul identitas mahasiswa.
- `ssh_modul.py`: Modul pengecekan SSH.
- `snmp_modul.py`: Modul pengecekan SNMP.
- `netconf_modul.py`: Modul builder pesan XML NETCONF.
- `telemetry_modul.py`: Modul klasifikasi data telemetry.
- `main.py`: Script eksekusi utama.

## Cara Menjalankan
1. Buka terminal/PowerShell.
2. Aktifkan virtual environment (`venv\Scripts\activate`).
3. Pastikan VM berjalan dan port forwarding aktif.
4. Jalankan perintah: `python main.py`
